### 13. What happens when I uninstall Search Pie app? <a href="#howtoremoveeverythingthatwehavesetupwithourapp" id="howtoremoveeverythingthatwehavesetupwithourapp"></a>

Since June 1st, 2023, according to [Shopify policy](https://shopify.dev/docs/apps/store/built-for-shopify/criteria#criteria), certain app codes are automatically removed from online store themes after the merchant uninstalls the app. Therefore, please note that except for the ALT tags and compressed images that are saved on your database already, other app codes (for example, meta title/description, schema & snippet, instant page, AMP, etc.) will be cleared away when you uninstall the Search Pie app.

{% hint style="info" %}
*Notice: If you turn off the app extension (Search Pie snippet) before uninstalling, meta tags that are set up with the app earlier can be saved.*
{% endhint %}
