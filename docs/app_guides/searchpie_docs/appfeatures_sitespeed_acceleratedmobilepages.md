# Accelerated Mobile Pages

Accelerated Mobile Pages (AMP) is a web component framework, which aims to improve the user experience with a faster loading speed of mobile pages. AMP pages always come high on the list of priorities of Google because the page takes less time to crawl. In other words, with AMP, your Shopify shop is going to be a user-oriented and mobile-friendly website, which is a straightforward way to a high page experience score.&#x20;

Concerning the importance of this component in SEO and user experiences, Search Pie offers an out-of-the-box tool for Shopify merchants by automatically creating AMP pages for your store.

### 1. Customize AMP pages

Before you can create any AMP pages, you'll need to choose from one of the following four themes (Glowing, Alia, Helis, Pastry)

<figure><img src="/files/GTZauRt247S9eO7kLKrA" alt=""><figcaption></figcaption></figure>

Each theme offers a unique design that suits different types of content. Please select the theme that best fits your store's needs and style. Once you've chosen a theme, you can easily proceed to create AMP pages.&#x20;

Each theme comes with: **Preview** and **Select**.

* **Preview**: When you click this button, a popup will open displaying a sample of the selected theme. This sample is fixed and does not import any of your data. You can interact with the preview just like a real website.
* **Select**: After reviewing the preview, you can choose to select the theme for your AMP pages.
* **Close**: If you decide not to proceed, simply click the close button to exit the preview.

## How to set up Integration Apps - Analytics?

### Google Analytics

Google Analytics is an essential tool for tracking the SEO performance of AMP pages. Search Pie app will help you add AMP Pages to Google Analytics in just via one step. All you need to do is filling the tracking ID (a string like UA-000000-2) of Google Analytics, and the app will finish other setups for you.

To find the tracking ID of Google Analytics, please follow this step-by-step guide from Google:

1\. Sign in to your Analytics account.

2\. Click Admin.

3\. Select an account from the menu in the ACCOUNT column.

4\. Select a property from the menu in the PROPERTY column.

5\. Under PROPERTY, click Tracking Info > Tracking Code. Your tracking ID and property number are displayed at the top of the page.

After getting the tracking ID, please enter it in the box of Google Analytics, then click Save & Publish button.

According to Analytics Help, “Once you have successfully installed the Analytics tag, it can take up to 24 hours for data such as traffic-referral information, user characteristics, and browsing information to appear in your reports”. However, to verify that your tag is working right now, you can check your Real-time report, which shows your current activity on your site.

1\. Sign in to your Analytics account.

2\. Navigate to a view in the property to which you added the snippet. If you only recently added the snippet to this property (website), it is likely that there will only be one view.

3\. Open Reporting.

4\. Select Real-Time > Overview

5\. You will see one view of AMP pages here, it points out that the tracking ID is successfully added to your AMP pages.

### Facebook Pixel

The Facebook Pixel is an analytics tool that helps you measure how effective your Facebook ad campaigns are by monitoring the actions people take on your website.

Firstly, please create a Facebook pixel.

1\. Go to Events Manager.

2\. Click Connect Data Sources and select Web.

3\. Select Facebook Pixel and click Connect.

4\. Add your Pixel Name.

5\. Enter your website URL to check for easy setup options.

6\. Click Continue.

After you have your pixel, please get it and enter it in the box of Facebook Pixel on the Search Pie app.

1\. Go to Events Manager.

2\. Select the pixel you want to set up.

3\. Click Continue Pixel Setup.

3\. Select Facebook Pixel and click Connect.

4\. Select Install code manually.

5\. Copy the pixel base code.

You can see more about how to get Facebook Pixel here: <https://www.facebook.com/business/help/952192354843755?id=1205376682832142>

### Google Tag Manager AMP Container ID

Tag Manager features an AMP container type. Create a new AMP container for your project:

1. On the [**Accounts**](https://tagmanager.google.com/#/home) screen, click **More Actions** for the account you'd like to use. Select **Create Container**.
2. Name the container. Use a descriptive name, e.g. "*example.com - news - AMP*".
3. Under **Where to Use Container**, select **AMP**.
4. Click **Create**.

Your container is now ready. The next step is to copy and paste it into the box on Search Pie.

## :question: FAQ About AMP

{% hint style="info" %}
**Why do the AMP pages not have an absolutely similar look to the original pages?**&#x20;
{% endhint %}

The AMP pages are set in a default theme from Search Pie, which is believed to be the most optimized interface for your store on mobile phones. Besides, to optimize the loading speed of mobile pages, AMP will prioritize delivering the most essential content of the web page,  therefore, it might look different from your original pages.

{% hint style="info" %}
**Do AMP pages change my store's mobile design?**&#x20;
{% endhint %}

No. Your orginal mobile design will stay unchange, the AMP pages won't change your mobile design.&#x20;

{% hint style="info" %}
**Why don't my AMP design change appear on Mobile?**&#x20;
{% endhint %}

Please ensure you are viewing the correct AMP URL, not the orginal mobile URL. This is example of AMP URL:&#x20;

<figure><img src="/files/jeoIqxo9q0LYCWalFW8O" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
**How long does it take for Google to index AMP pages?**
{% endhint %}

Usually, Google takes 7 - 10 days to index AMP pages, and it also depends on how often Google crawls your website.&#x20;

{% hint style="info" %}
**How does AMP benefit SEO?**
{% endhint %}

Google's ranking systems apply a set of standards to all websites on the search result page. It means that thanks to the advantage of loading speed, AMP pages will be evaluated and ranked higher by Google on mobile devices because mobile-friendly is one of the most essential ranking factors for Google.

{% hint style="info" %}
**How to check if AMP is successfully integrated or not?**
{% endhint %}

To make sure that AMP pages are successfully integrated, you can go to your original pages, right-click and click on “View Page Source,” or press Ctrl + U, to see the page's source. In the new tab, press Ctrl + F, and fill “amp” in the box, if you find the AMP link on the HTML code, it points out that AMP was enabled successfully.

The AMP links will look like this example: <br>

![](https://lh6.googleusercontent.com/7FDffSP4VVB-YA9F4Q89OQNlGohsVOKeM3yvNRErUNGWrW2vhaDRgOWjERHFEw_vQyCUnP2freuFoZEcGN2VWLk9TK5XDNu35th_aZP0qsZknnPqBdnggm3L8FbRzMf5mnnYC861)

When Google crawls your site, it will find out this "href" of the meta tag, which points to your AMP pages, and then Google might index them in some days.
