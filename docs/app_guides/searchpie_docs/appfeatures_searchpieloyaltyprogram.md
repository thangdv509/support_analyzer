# SearchPie Loyalty Program

The **SearchPie Loyalty Program** is a structured customer rewards system designed to strengthen engagement, retention, and long-term monetization. It combines two complementary elements:

* **Loyalty Tiers** – a spending-based system that recognizes and rewards customers as they increase their purchasing activity.
* **Loyalty Badges** – an action-based system that encourages customers to interact with your brand beyond transactions.

At the core of the program is our exclusive loyalty currency, **Pie Points (🍰)**. Customers earn Pie Points through purchases and qualified actions, which can then be redeemed for meaningful rewards. This creates a continuous cycle of motivation, satisfaction, and loyalty.

If you’re ready, let’s get started 👌
