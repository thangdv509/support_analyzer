# How do I approve SearchPie's partner request?

## I. Grant new permission for SearchPie account:

### Step 1: Send us the Collaborator Request Code (if necessary):

If your store is set up with he Collaborator Access Cod&#x65;*,* you need to send us your collaborator request code so we can send you the access request.&#x20;

Please go to **Shopify Settings > choose Users > Security** and then send us the code via Livechat.&#x20;

<figure><img src="/files/YO6U6a882CS3YDYArOQd" alt=""><figcaption></figcaption></figure>

### Step 2: Review & Accept our access request

After we send you the access request, please go to **Shopiy Settings > Users** and click it to check our access request here.&#x20;

<figure><img src="/files/fKNXjzUNpZVJGeNtijkI" alt=""><figcaption></figcaption></figure>

Normally, we need access to your Theme & SearchPie app. Therefore, you need to click **Edit Permission,** then **scroll down to make sure you tick the SearchPie app, theme & edit code.**

## II. Update permission for SearchPie account:&#x20;

When we already have access to your store, but you want to update some new permissions. You can follow our steps below:&#x20;

Let's go to Shopify settings > Users > Roles. Here, you need to select our SearchPie access, and then tick the permissions you need to update before clicking **SAVE**. After that, the role is updated successfully.&#x20;
