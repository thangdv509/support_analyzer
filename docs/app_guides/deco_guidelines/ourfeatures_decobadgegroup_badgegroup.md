# Badge Group

## How Label Group Works

* **Without Label Group**\
  Labels are positioned individually, requiring manual spacing adjustments, risking overlap, and inconsistent spacing.
* **With Label Group**\
  Labels automatically stack and adjust position when others are removed (smart positioning)

## Step-by-Step Setup Guide

### ✨Step 1: Create Individual Labels

* Design your labels first **( Skip this step if you already have labels created )**

**Example:**

* "Bundle & save 15%"
* "Coming soon"
* "Halloween sale"
* "Extra 15% off"

<mark style="color:blue;">**(Or please take a look at the short video below to know where to create a DECO label)**</mark>

{% embed url="<https://www.loom.com/share/11cd5982b17c482288bd9423f4774f91?sid=72db18b2-dab5-4188-a6eb-c3adb5dcfa13>" %}

### ✨Step 2: Access Label Group

* Navigate to the "***Badge groups***" section in your DECO dashboard >> **Click&#x20;*****"Create group"*****&#x20;>> Choose:&#x20;*****"Label group"***&#x20;

<figure><img src="/files/Vz5YcVK0vfFWAZyW4SVd" alt=""><figcaption></figcaption></figure>

### ✨Step 3: Add Labels to group

* In "*<mark style="color:$success;">**Select labels**</mark>*" tab >>  Hit on "*<mark style="color:$success;">**Add labels to group**</mark>*" button to add labels you want to group together

<figure><img src="/files/Ji5u7xwVgrvovoROMUz0" alt=""><figcaption></figcaption></figure>

* **Tick** to choose labels >> Click "**Done**" to save the order

{% hint style="info" %}
**Important:** The selection order determines the display order
{% endhint %}

<figure><img src="/files/5ArH1PRYWBrEMrP2Y1GQ" alt=""><figcaption></figcaption></figure>

### ✨Step 4: Customize Design

1. *<mark style="color:blue;">**Go to the "Design" tab**</mark>*
2. *<mark style="color:blue;">**Choose label position:**</mark>*

   * Top left
   * Top right
   * Bottom left
   * Bottom right
   * Center

   <figure><img src="/files/ckk3NWGxsQgtSIPD31ZW" alt=""><figcaption></figcaption></figure>
3. *<mark style="color:blue;">**Select layout orientation:**</mark>*

   * **Horizontal:** Labels side by side
   * **Vertical:** Labels stacked

   <figure><img src="/files/0mJOHtRJV4CJv0MO5rHw" alt=""><figcaption></figcaption></figure>
4. *<mark style="color:blue;">**Adjust the spacing between labels**</mark>*

<figure><img src="/files/gS4C9pUB0rT9vFWjClHC" alt=""><figcaption></figcaption></figure>

### ✨Step 5: Preview & Publish

1. Click **"Save"** to apply changes
2. Preview your label group on your store
3. Make adjustments if needed
4. Publish when satisfied
