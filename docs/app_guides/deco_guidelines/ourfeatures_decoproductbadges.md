# DECO Product Badges

## 🔖 **What is a DECO Product Badge?**

* A Badge is any graphic element laid **INSIDE/OUTSIDE OF AN IMAGE** to provide additional information, context, or identification for your products.

## 🛠️ Where to create a badge?

* There are 2 WAYS:&#x20;

1/ From the DECO's home page,&#x20;

* To ***create*** a new badge: Click: <mark style="color:blue;">"</mark>*<mark style="color:blue;">**Create"**</mark>* button in the Label & Badge block to get started.
* To ***quickly view*** all badges created: Click: *<mark style="color:blue;">**"Manage"**</mark>*

<figure><img src="/files/m6eKinmeO0CzOXiNQaA4" alt=""><figcaption></figcaption></figure>

2/ Or navigate to <mark style="color:$primary;">"</mark>*<mark style="color:$primary;">**Labels &**</mark>* *<mark style="color:$primary;">**Badges**</mark>*<mark style="color:$primary;">"</mark> on the left navigation menu >> Then, click <mark style="color:$primary;">"</mark>*<mark style="color:$primary;">**Create badge**</mark>*<mark style="color:$primary;">"</mark> to get started

<figure><img src="/files/D42EOiIj6hF3yAzpcJhE" alt=""><figcaption></figcaption></figure>

## ⚙️Choose The Badge Type

* Then, select 1 type of the badge >> Click "***Create***" button to get started:

1/ <mark style="color:blue;">**Text badge**</mark><mark style="color:$info;">**:**</mark>  The ***editable type***, which **you can edit anything**, like shape, background color, content, text color, etc

2/ <mark style="color:blue;">**Image badge**</mark>: The ***pre-made*** type, which **you can't edit**. However, if you require any modifications to the template, please don't hesitate to contact our support team for assistance.&#x20;

<figure><img src="/files/c7MoPx6UPuUe7twxfiLG" alt=""><figcaption></figcaption></figure>

{% hint style="info" %} <mark style="color:blue;">**NOTE**</mark>: **Once you selected the badge type (Image/Text)** in this screen, **you couldn't change the badge type in the next step** (if you would like to change, you need to create a new badge)
{% endhint %}
