# Discount Code

First, like Automatic Discount, in the Discount Code settings, you can:&#x20;

* Set the campaign name, this won't be seen by your customers
* Set your campaign start time/end time&#x20;
* Change the product that you want to preview

<figure><img src="/files/4AzHMnyKha0NUsW96W9C" alt=""><figcaption></figcaption></figure>

After which, you can choose which type of discount that you want to apply. You have the following options:&#x20;

* Percentage (%)&#x20;
* Fixed Amount ($)&#x20;
* New price ($)&#x20;

<figure><img src="/files/z6AQe4EwNJIPU9EFswqM" alt=""><figcaption></figcaption></figure>

After setting up the type of discount that you want, you can also set the code for your discount or generate a discount code

The discounted amount will automatically show in the preview also.&#x20;

Finally, you can select which products the discount applies to and create badges to showcase your discount codes (optional):&#x20;

<figure><img src="/files/QmD9btTljMcL84P9ejKB" alt=""><figcaption></figcaption></figure>

## Combinations

The **Combinations settings** allow you to use DECO discounts alongside Shopify discounts at the same time, giving you more flexibility to run multiple promotions together:&#x20;

* Product Discounts: Allows usage of multiple discounts from both Shopify and DECO to products for more flexible promotions&#x20;
* Order Discount: Allows you to display discounts for all orders that meet the eligible purchase amount criteria&#x20;
* Shipping discounts: Allows shipping discounts to be applied on top of existing product discounts, enabling more attractive combined promotions.
