# Show Badge Based On Store Languages

{% hint style="info" %}
**NOTE**: This feature is available for *<mark style="color:$primary;">**Badge only**</mark>*
{% endhint %}

## Where It Is?

* Navigate to *<mark style="color:$primary;">**"Labels & Badges"**</mark>* on the navigation menu&#x20;
* Click the *<mark style="color:$primary;">**pencil icon**</mark>* to open a badge

<figure><img src="/files/qgLyTjev2Vwlc5KljQaa" alt=""><figcaption></figcaption></figure>

* Next, move to "Display" tab >> Scroll down to: "*<mark style="color:$primary;">**Show badges on store languages**</mark>*" section

<figure><img src="/files/4aaMkOV1kb57JCVUYteN" alt=""><figcaption></figcaption></figure>

## Choose languages

* Select: *<mark style="color:$primary;">**"All Languages"**</mark>*: The badge will be *<mark style="color:$primary;">**visible in all languages**</mark>* on your website.
* Select *<mark style="color:$primary;">**"Custom Languages"**</mark>*<mark style="color:$primary;">:</mark> The badge will *<mark style="color:$primary;">**only appear**</mark>* when *<mark style="color:$primary;">**customers select specific languages you set up in the DECO app.**</mark>*

<figure><img src="/files/hxoNKe4wKk3XjPWYbzzU" alt=""><figcaption></figcaption></figure>
